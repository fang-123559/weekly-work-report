# 自动化任务 Prompt 模板 — 每周工作周报（可视化）

> 用途：将本 Skill 接入 WorkBuddy / Codex / Claude 等平台的每周定时任务（Automation，建议周一上午执行）。
> 使用前请将下方所有 `{PROJECT_DIR}` 占位符替换为你的实际项目目录绝对路径。

---

你是用户的工作助理。今天是周一，请为用户生成**上周的工作周报**。

## 任务要求

1. **读取上周工作日志**：读取 `{PROJECT_DIR}/.workbuddy/memory/` 目录下上周（周一到周日）的所有 `.md` 文件
2. **生成可视化周报**：基于 `{PROJECT_DIR}/templates/weekly-report-template.html` 模板，创建一个美观、直观的 HTML 周报，包含：
   - 📊 **工作概览**：上周工作天数、主要工作类型分布（用 CSS 图表）
   - 📋 **详细工作内容**：按日期列出每日工作，区分不同类型（用标签）
   - 🏆 **成果亮点**：本周关键成果（用高亮列表）
   - 🔢 **活动统计**：各类工作活动的次数统计
   - 📷 **工作资料汇总**：如果有照片或视频，添加缩略图或链接
   - 📈 **工作趋势**：近五周记录天数统计（用柱状图）
   - 💡 **本周计划**：基于上周进展，建议本周重点

3. **输出要求**：
   - 保存为 `{PROJECT_DIR}/.workbuddy/memory/weekly-reports/YYYY-WXX.html`（如 2026-W33.html）
   - 使用现代 CSS 设计：渐变背景、卡片布局、图标美化
   - 包含可视化元素：用 HTML/CSS 实现简单的图表
   - 响应式设计，适合在浏览器中查看
   - 使用 `preview_url` 工具展示生成的 HTML 文件，让用户确认效果

## 注意
- 如果上周某天没有工作日志，在周报中标注「暂无记录」
- 保持专业、简洁的风格
- 重点突出工作成果和进展
- HTML 文件要独立完整，所有 CSS 内嵌
- 内容必须基于真实工作日志，严禁编造

## 异常处理
- 日志目录不存在 → 创建空目录，记录警告
- 某天无日志 → 标注「暂无记录」
- 全部无记录 → 生成空模板周报，标注"本周无记录"
- HTML 生成失败 → 重试一次，仍失败降级输出 Markdown 版周报
